Fitur Utama Sistem

Semua yang dibutuhkan untuk pengelolaan nilai siswa dalam satu platform

Manajemen Data Siswa

Kelola data siswa lengkap dengan NIS unik, nama, dan kelas. Admin dapat menambah, mengubah, dan menghapus data dengan mudah.

Input Nilai Otomatis

Guru menginput nilai Tugas, UTS, dan UAS. Nilai akhir dihitung otomatis dengan rumus yang telah ditentukan beserta grade dan status kelulusan.

Laporan & Rekap Nilai

Tampilkan laporan nilai per kelas, per semester, dan per tahun ajaran. Lengkap dengan grade A–E dan status lulus atau tidak lulus.

Hak Akses Berbasis Role

Tiga role berbeda: Admin dengan akses penuh, Guru untuk input dan rekap nilai, serta Siswa untuk melihat nilai pribadi mereka.

Manajemen Mata Pelajaran

Admin dapat mengelola daftar mata pelajaran yang tersedia di sekolah, lengkap dengan kode dan deskripsi mata pelajaran.

Database MongoDB

Data tersimpan aman di MongoDB dengan struktur yang terorganisir. Didukung JWT Authentication untuk keamanan akses sistem.

Siapa yang Menggunakan?

Sistem ini dirancang untuk tiga jenis pengguna dengan hak akses yang berbeda

Admin
  • Kelola data siswa (CRUD)
  • Kelola data guru (CRUD)
  • Kelola mata pelajaran
  • Lihat dan hapus semua nilai
  • Tampilkan laporan per kelas
Guru
  • Input nilai siswa per mata pelajaran
  • Edit nilai yang sudah diinput
  • Lihat rekap nilai per kelas
  • Preview kalkulasi nilai akhir
  • Validasi nilai mata pelajaran
Siswa
  • Lihat nilai semua mata pelajaran
  • Lihat nilai akhir dan grade
  • Lihat status kelulusan
  • Filter per semester & tahun ajaran
  • Lihat ringkasan rata-rata nilai

Rumus Perhitungan Nilai

Nilai akhir dihitung otomatis berdasarkan bobot yang telah ditentukan

Formula Nilai Akhir

Nilai Akhir = (30% × Tugas) + (30% × UTS) + (40% × UAS)

Rentang nilai valid: 0 – 100  |  Lulus jika Nilai Akhir ≥ 70
